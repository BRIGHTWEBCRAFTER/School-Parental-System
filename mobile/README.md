# 🎓 School-Parental System App

A comprehensive mobile application built with Flutter to bridge the communication gap between schools and parents. This app allows parents to securely access their child's academic records, monitor attendance, receive real-time school announcements, and stay updated with upcoming school events.

## Key Features

*   **Secure Authentication:** Parents log in using their registered phone number or email address.
*   **Interactive Dashboard:** A central hub showing the selected learner's school, quick access to features, and recent announcements.
*   **Multi-Child Support:** Parents with more than one child enrolled can easily switch between them using a dropdown menu.
*   **Academic Tracking:** View latest subject grades, detailed assessment histories, and term averages.
*   **Attendance Monitoring:** Check daily and monthly attendance records.
*   **Announcements & Notifications:** Receive real-time school announcements with unread badges on the app bar.
*   **School Events:** View upcoming school events filtered by grade or role (e.g., Whole School, Parents, Grade 4).
*   **Report Cards:** View and download official PDF report cards uploaded by the school.

## 🛠️ Technology Stack

*   **Framework:** [Flutter](https://flutter.dev/) (Dart)
*   **State Management:** [Provider](https://pub.dev/packages/provider)
*   **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL)
*   **Authentication:** Supabase Auth
*   **File Storage:** Supabase Storage (for avatars, reports, and school logos)
*   **UI/UX:** Material Design 3
